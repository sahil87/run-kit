TMUX WINDOW OPTIONS (shared state — what every viewer & agent sees)
drafts are viewer-local — nothing in tmux until Enter
  • Empty tab: click the strip's + (or double-click empty strip space) — a dashed draft tab appears and the address bar arms. Type localhost:5173 and hit Enter to materialize it. Open several drafts; note the inspector — drafts never touch tmux.
  • Discard a draft: Esc in the address bar, or its ×.
  • Reorder: drag a tab left/right; or focus the strip and press ⌥⇧← / ⌥⇧→ to move the active tab. Watch the slot values permute in the inspector (web/<n>/move verb).
  • Close: × or middle-click a tab — dense renumber, active repoints, exactly the shipped rule.
  • Titles: a materialized tab shows a spinner, then its page title + favicon (falling back to today's kind-dot + URL-derived label).

Why drafts are viewer-local, not a sentinel URL

A stored blank tab fights three spec decisions at once: identity is the URL (two blanks collide), empty = unset (an empty option value can't exist), and declared only. A draft is a place to type an address — compose-draft class state per the One Rule. The moment it has content worth sharing (an address), it becomes a real slot.
