Control Contract Preview

Settled 2026-09-05: · Hue scheme C — neutral + green: hover is pure brightness (white ink/border, hue-free glint), green appears only when something is ON; blue retires from controls · Coarse floor 40px for bar buttons and chips (fine sizes unchanged) · every control carries user-select: none + -webkit-user-select: none + -webkit-touch-callout: none so a long-press never selects the glyph or pops the iOS callout · bottom bar recomposed: ⌥ and the arrow pad move into the F▴ menu.

Everything below runs on one recipe (the .ctl block in this file's CSS) plus size classes. Hover, Tab, click-to-latch, and press-and-hold are all real — and so is the long-press guard: hold any chip and nothing selects.

What ships

Tokens: --ctl-h-bar 28 / 40 coarse · --ctl-h-chip 33×35 / 40 coarse · --ctl-h-row 28 / 40 · --ctl-radius · --ctl-ring (2px green, offset 2) · --ctl-duration · latch/press fills as color-mix of theme tokens.

Base recipe additions: user-select: none; -webkit-user-select: none; -webkit-touch-callout: none; on every control (chips, buttons, menu rows, segments).

Two global rules: the :where(…):focus-visible green ring, and the glint moved to a hue-free sweep with its color-override rule deleted (scheme C makes the §2 cascade problem moot — there is no hover hue left to fight the latch).

One primitive: Control (icon · chip · toggle · segment · menu-row · wide) + the bottom-bar recomposition (⌥ + arrows → F▴ menu) as its first consumer.
