Chapter 8 · The operator

One agent per server whose job is running the other agents. You don't command it — you ask it, in plain language.

1the operator is an ordinary window row pinned at the top of its server group, above that server's session rows. Placement is the only difference; click into it like any window.

things you say to it
❯ Start a claude session on my-app
❯ Start a kimi session
❯ Start a claude session, but with codex workers
❯ What's stuck? Anything waiting on me?

It spawns the sessions, wires the worktrees and workers, watches the blocked markers from Chapter 2, and answers agents' pending questions when it safely can.

The arc of this tour: chapters 1–7 taught you to read and drive one workspace. The operator is how it scales — you stop managing windows and start delegating.
