Act 2 · Make it show you things

Stop reading agent output in a terminal. Ask for it as a page.

“…and present it to me”

End any request with that phrase — every agent in run-kit knows what it means. This very page arrived that way.

what to ask for
  • reports & briefs — "summarize this sprint's changes and present it to me"
  • mocks & prototypes — "mock the new settings screen and present it to me"
  • dashboards — "chart the test failures by day and present it to me"
  • a running dev server or any URL — "present localhost:3000 to me"

And iteration is just asking again — "make the heading bigger" refreshes the same page in place.
