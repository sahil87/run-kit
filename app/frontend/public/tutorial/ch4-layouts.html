Chapter 4 · Arranging the view

The tile arrangement is shared state — one tmux option, @rk_win_layout, that you, the toolbar, and agents all write.

the value grammar

<shape>:<surface,surface,…>   e.g.  split-v:web,tty — each shape takes exactly the tile count labelled below; first surface fills slot A

Surfaces: tty (this terminal — always present) · web (this page's tile) · code (the editor, next chapter) · chat.

one verb table — buttons and CLI are the same writes
rk tab layout split-v:web,ttystack two surfaces, web on top
rk tab layout --promote ttymove tty into slot A
rk tab layout split-h:tty,webplace the same two surfaces side by side
rk tab layout --add code / --rm codegrow / collapse a tile
rk tab layout --cyclestep through shapes

Watch the top bar: the surface toggles light up to mirror every change — human clicks and agent commands drive one table. (Shell writes render on the next poll — give them a few seconds. Divider ratios and zoom stay yours per-device.)
