3 · The mechanism (why it's cheap)

# one window-scoped tmux user option; value = epoch prefix + free text @rk_note = 1756036800:blocked on flaky e2e # read: field 14 of the list-windows derive (free text ⇒ last field, tail-rejoined) list-windows ─▶ parseWindows ─▶ WindowInfo{Note, NoteEpoch} ─▶ /api/sessions + SSE ─▶ every client # write: 7th key on the existing /options allowlist (validated: ≤120 chars, no control runes) # survives restarts: rides layout snapshots · dies with the window · absent ⇒ rendered nowhere

This is the pattern worth reusing: one derived option + one payload field buys every surface at once — anything that already receives the window payload (sidebar, boards, desktop shell, palette, operator facts) can render or search notes with a render-only change.
