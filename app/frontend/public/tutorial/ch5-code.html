the code root — one shared folder per tab

@rk_win_code_root seeds itself from the pane's git root the first time the tile opens, then stays put — a cd in the terminal never yanks your editor. It moves only when you navigate (File → Open Folder) or someone runs rk tab code set <folder>.

agents can drive the editor

rk code exec vscode.open '{"$uri":"file:///…/README.md"}' → the file opens in the tile. Any VS Code palette command works — refresh a PR list, open a diff, focus a view. (The channel: a local socket into the editor — the one surface whose interior isn't tmux state.)
