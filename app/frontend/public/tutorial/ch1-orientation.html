Chapter 1 · Where am I

run-kit renders tmux — first the conceptual hierarchy, then the shipped desktop status bar.

the layer stack
1Host — the machine running rk serve (the dashboard you're in)
2tmux Server — one socket, many sessions
3Session — usually one per project
4Window = a “tab” — one sidebar row, addressed @N
5Pane — a real shell; your tutorial agent lives in one (%N)
zoom in: the shipped desktop status bar
W⑂ rk-tutorial fab apply agt waiting tmx pane 1/1 %185 cwd rk-tutorial │ Hcpu 18% mem 4/16G default workstation v1.2.3
  • Wthe current window's derived registers, active-pane identity, and working directory
  • Hhost metrics, then the tmux server name and host/version details
  • →session and window navigation live in the sidebar; rk url prints in the terminal, not this bar

The rule: everything the dashboard shows is derived from tmux at request time — there is no database. When the agent changes tmux state, every viewer's UI follows.
