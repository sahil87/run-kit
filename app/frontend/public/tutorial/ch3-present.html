Chapter 3 · Show, don't tell

Any agent in a run-kit pane can put a live web page beside its own terminal — this page arrived exactly that way.

the flow
agent
writes report.html
→
rk present ./report.html
serves it live
→
web tile opens
beside the terminal, every viewer sees it
“…and present it to me”

That phrase is the trigger. Say it to any agent in a run-kit pane — it matches the skill that teaches agents rk present. Reports, diagrams, mocks, dashboards: ask for them as pages, not prose.

what present accepts
rk present ./mock.htmla file — served from the live filesystem
rk present ./dist/a directory (serves its index.html)
rk present :5173a port already serving — your dev server, proxied (works from your phone too)
rk present https://…an external URL, embedded when the site allows it

Refresh rule: re-running the same rk present re-navigates the open tile — re-present is the refresh verb. Plain reloads already see file edits (it serves live).
