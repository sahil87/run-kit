Act 1 · You have an agent

The sidebar is your roster. Every row is an agent (or a plain terminal) working for you.

how to read a row
  •  busy — the agent is working; you don't need to watch it
  •  idle — finished; results are in its window, ready for the next ask
  •  needs you — it asked a question and is waiting. This badge is the whole game — you'll trigger one for real in Act 4.

Try it now: ask me anything about this project — then watch my row flip busy while I answer, idle when I'm done.
